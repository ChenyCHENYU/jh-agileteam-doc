# 平台核心概念

> 低代码平台的四要素：**模型、页面、接口、流程**。理解这四个概念，就能理解平台所有功能模块的设计逻辑。

---

## 四要素关系

```text
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│   模型    │ →  │   接口    │ →  │   页面    │    │   流程    │
│ (数据层)  │    │ (逻辑层)  │    │ (展示层)  │    │ (流转层)  │
│          │    │          │    │          │    │          │
│ 数据库表  │    │ CRUD/   │    │ 列表/表单 │    │ 审批/通知 │
│ 字段定义  │    │ 自定义   │    │ 大屏/门户 │    │ 工作流   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
      ↑               ↑               ↑               ↑
  模型设计        接口管理        页面设计        流程管理
```

**核心逻辑**：模型定义数据结构 → 接口提供数据操作 → 页面消费接口展示 → 流程串联页面审批。

---

## 1. 模型（数据层）

模型是数据库表的可视化抽象。平台支持两种模型：

| 模型类型 | 对应 | 适用场景 |
|---------|------|---------|
| [单表模型](/platform/model-design) | 一张数据库表 | 简单 CRUD |
| 多表模型（关系模型） | 多张关联表 | 主从/多对多关系 |

模型设计完成后，平台**自动生成**对应的数据库表、Entity/DTO/VO 类、CRUD 接口。

**字段业务类型**（决定前端组件和后端校验）：

| 类型 | 说明 | 生成的前端组件 |
|------|------|-------------|
| dict | 数据字典 | jh-select（下拉） |
| user | 用户 | 用户选择器 |
| date / datetime / time | 日期/时间 | jh-date |
| number | 数字 | jh-input-number |
| auto_no | 自动编码 | 系统自动生成 |
| text / textarea | 文本 | input / textarea |

---

## 2. 接口（逻辑层）

接口是前端页面与后端数据的桥梁。平台支持四类接口：

| 接口类型 | 生成方式 | 入口 |
|---------|---------|------|
| 标准 CRUD | 模型提交后自动生成 | 无需操作 |
| [逻辑编排](/platform/api-management) | 可视化拖拽编排 | 接口管理 → 逻辑编排 |
| [敏捷接口](/platform/api-management) | 配置 SQL + 参数映射 | 接口管理 → 敏捷接口 |
| 外部接口 | 注册第三方系统接口 | 接口管理 → 外部接口 |

接口生成后通过**接口收集**注册到平台，供权限挂载和页面绑定。

---

## 3. 页面（展示层）

页面是用户交互的界面。平台提供四种页面构建方式：

| 页面类型 | 入口 | 适用场景 |
|---------|------|---------|
| [页面设计器](/platform/page-design) | 低代码 → 页面设计 | 业务 CRUD 页面（拖拽组件） |
| [门户页设计](/platform/portal-design) | 低代码 → 门户页设计 | 系统首页门户 |
| [可视化大屏](/platform/dashboard) | 低代码 → 大屏设计 | 数据可视化看板 |
| [快速搭建](/platform/quick-start) | 低代码 → 快速搭建 | 模型+页面+流程一站式 |

页面设计器的核心能力：

- **组件库**：基础组件 / 高级组件 / 页面组件
- **数据源**：绑定接口，配置请求参数和响应映射
- **大纲树**：页面结构管理
- **画布**：所见即所得拖拽

---

## 4. 流程（流转层）

流程是审批业务的核心引擎。

| 能力 | 入口 |
|------|------|
| [流程模板管理](/platform/workflow) | 流程管理 → 流程模板 |
| 流程参数 | 流程模板 → 参数配置 |
| 流程表单 | 流程模板 → 表单设计 |
| 流程图 | 流程模板 → 流程图设计 |
| [通知中心](/platform/notification) | 通知配置 |

流程与模型的关系：模型开启"审批流"后，快速搭建会增加流程参数配置、流程表单编辑、流程图设计三个步骤。
