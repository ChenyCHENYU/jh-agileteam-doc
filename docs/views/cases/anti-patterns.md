# 反模式合集 · 8 条事故复盘

> 每条 5 行：现象 / 根因 / 沉淀规则 / 一行命令。规则背后的"为什么"，30 秒一条。

---

### 1. 弹窗里的表格"看不见"

- **现象**：弹窗内 AG Grid 首次打开零高度，数据在但表格不显示。
- **根因**：弹窗动画未结束时初始化 Grid，容器高度为 0。
- **沉淀规则**：**K19** —— 弹窗内 AG Grid 必须 `v-if` 延迟挂载。
- **命令**：`wl-skills validate`（K19 命中即报）。

---

### 2. 测试文件写了，却从未真正执行过

- **现象**：e2e 工程看着齐全，一问执行记录没有；`test.only` 遗留导致只跑了 1 条。
- **根因**：没有归属清单与执行闭环，"写了"被当成"测了"。
- **沉淀规则**：**T21-T25** + 用例归属强校验（未归类/重复归属/缺安全标记拒绝运行）。
- **命令**：`wl-skills-test e2e-check --target ./e2e/`。

---

### 3. 数据库里有字段，没人知道谁加的

- **现象**：线上库出现文档和 Flyway 都没有的列（"无主变更"）。
- **根因**：现场绕过流程手工直改库，无登记。
- **沉淀规则**：**B31** 四方对账 + DDL 执行账本（`db executed` 带审批引用）。
- **命令**：`wl-skills-bd db drift --snapshot snapshot.json`。

---

### 4. 编译通过，Spring 启动报 ClassNotFound

- **现象**：EasyExcel 编译正常，运行时容器扫描报类缺失。
- **根因**：业务模块私锁了父 BOM 已管理依赖的版本。
- **沉淀规则**：**B27** —— 父 BOM 管理的运行时依赖禁止私锁版本（首批 EasyExcel）。
- **命令**：`wl-skills-bd validate src/main`（B27 命中即报）。

---

### 5. MapperScan 通配符扫出 Bean 冲突

- **现象**：启动报 Mapper Bean 定义冲突，排查半天定位不到。
- **根因**：`@MapperScan` 通配符扫到泛型 `BaseMapper`。
- **沉淀规则**：**B26** —— MapperScan 范围 / 泛型注册 / XML namespace 校验。
- **命令**：`wl-skills-bd validate src/main`（B26）。

---

### 6. 部分 Android WebView 整块样式失效

- **现象**：新页面在旧 PDA 上样式整体丢失。
- **根因**：CSS `@layer` 规则块被旧 WebView 直接丢弃。
- **沉淀规则**：Robot_H5 v1.7.0 移除 `@layer`，构建目标 ES2018 / Chrome 61 CSS。
- **命令**：`pnpm test:compat`（确认产物不含 `@layer`）。

---

### 7. kit 升级报 132 个文件被改过

- **现象**：Windows 项目 `update` 时几乎所有文件提示本地修改。
- **根因**：`core.autocrlf` 换行符差异被当成内容变更。
- **沉淀规则**：内容身份按 LF 计算；真实改动才触发备份保护。
- **命令**：`wl-skills diff`（升级前核对）。

---

### 8. "AI 代码一次通过"，评审却吵了 30 楼

- **现象**：自评 AI 使用效果好，MR 讨论线程数是团队均值 2 倍以上。
- **根因**：照单全收式采用——采用率高但质量不达标（部门定级 L2 负向行为）。
- **沉淀规则**：客观指标交叉验证 + **review 门禁**（新增问题增量阻断）。
- **命令**：`wl-skills-bd review run --module <模块>`。
