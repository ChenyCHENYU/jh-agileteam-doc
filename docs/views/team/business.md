# 业务团队

> 信息化中心交付团队的业务侧：需求、设计与交付验收的源头。

## 职责范围

| 方向 | 内容 |
|------|------|
| 需求与设计 | 按规范产出需求说明书 / 原型标注 / 数据库与接口设计（[wl-skills-design](/views/ai-workflow/design-skills) 的使用方） |
| 交付验收 | 以 `verify` 机械校验 + 集成评审报告作为设计侧验收依据 |
| 变更管理 | 跨域变更先跑[变更影响分析](/views/ai-workflow/design-skills)，出补丁清单后再动文档 |

## 与工程团队的接口

- 设计产物（说明书 / db-spec / 接口设计）是五包工作流的**输入起点**，质量决定下游生成精度（规范线 95-100% vs 原型线 90-95%）；
- 验收争议以机器报告（审计 / verify / gate）为准，不凭印象。
